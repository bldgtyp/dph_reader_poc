# corpus — the reference models

The designPH models and companion files the whole project's evidence rests on. **Hard rule 3
applies to everything here: never modify a corpus file — copy before experimenting.**

| Folder | What it is |
|---|---|
| [`adelphi/`](adelphi/.index.md) | **The primary corpus** — one real building in six formats (`.skp`, `.hbjson`, PHPP, `.ppp`, `.3dm`, `.gh`). ⚠ In this cleaned copy the data files are removed ([`../DATA_REMOVED.md`](../DATA_REMOVED.md)); the index keeps their descriptions because the rest of the repo cites them |
| [`synthetic/`](synthetic/.index.md) | The six-face hand-made test model + BT Attribute Inspector dumps. Safe for *mechanics* testing; ⚠ **never generalise a schema rule from it** — it produced the confidently wrong `*ID`/`*Auto` version rule |

**Secondary corpus (not in this repo):** 11 real project models under
`~/Dropbox/bldgtyp/*/08_DesignPH/*.skp`, spanning designPH 2.1.10–2.2.29, backups included. All 14
corpus models are baselined key-by-key in
[`../planning/01_sketchup-export/feasibility/RESULTS/PHASE-0_corpus-baseline.md`](../planning/01_sketchup-export/feasibility/RESULTS/PHASE-0_corpus-baseline.md)
— check there before opening a model by hand. Five are captured live (contract v2) in
`pocs/01_sketchup-export/_private/fixtures/` (gitignored client data, `MANIFEST.md`-tracked), and
sixteen through the headless reader in `planning/spikes/headless/_private/`.

⚠ **Adelphi is the simplest model in the corpus and it masks bugs** — never validate a rule or a
check on Adelphi alone (`AGENTS.md`, Corpus section).
