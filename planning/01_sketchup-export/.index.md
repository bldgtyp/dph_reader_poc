# planning/01_sketchup-export — POC #1: designPH → HBJSON, inside SketchUp

**✅ CLOSED PASS (Ed, 2026-08-21).** One menu item in SketchUp 2022 reads a real designPH model and
writes valid, standard HBJSON plus a translation report — a Ruby collector walks the model through
the public API, a Pyodide runtime inside `HtmlDialog` runs the real honeybee-ph stack, and the
result lands on disk. Proven on five real projects (designPH 2.1.15–2.2.29, SketchUp 22–26):
**545/545 classified faces · 239/239 windows · 99/99 thermal bridges**, U-values matching
designPH's own calculator, and the HBJSON loading in Rhino/Grasshopper and production ph-navigator.
