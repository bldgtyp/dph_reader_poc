## The rule

**Do not start a phase until the previous phase's gate has been evaluated and recorded.** The
sequence exists to stop early, not to complete all six. The same rule governed the POC build —
see [`../implementation/00_POC_OVERVIEW.md`](../implementation/00_POC_OVERVIEW.md).

⚠ These docs record what was *planned and learned on 2026-08-19*. Several conclusions were
overturned by the POC's real-model runs; for what is true now, read
[`../../../00_Context/`](../../../00_Context/.index.md).
