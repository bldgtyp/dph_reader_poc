# planning/02_headless-reader — POC #2: the headless reader

**POC #2 (opened 2026-08-28).** POC #1 (`../01_sketchup-export/`) closed PASS on 2026-08-21 and
proved the pipeline *inside* SketchUp; this POC asks
whether the same read can happen **with no SketchUp at all** — a headless service, driven by a
Dropbox watcher (the pholio model), scraping designPH data passively with no user in the loop and
no SketchUp seat on any server. The proposed route is the **SketchUp C SDK**.

**Read [`00_HEADLESS_OVERVIEW.md`](00_HEADLESS_OVERVIEW.md) first** — the question, why the C SDK,
the rules in force, and the licensing checklist.
