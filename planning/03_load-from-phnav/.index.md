# planning/03_load-from-phnav — POC #3: SketchUp LOADS data from PH-Navigator

**▶ STATUS: Requested — stub only (Ed, 2026-08-31). Not yet scoped.**

The first two POCs proved the **read/export** direction — designPH data out of a `.skp`, into
HBJSON, inside SketchUp ([`../01_sketchup-export/`](../01_sketchup-export/.index.md)) and with no
SketchUp at all ([`../02_headless-reader/`](../02_headless-reader/.index.md)). This POC asks about
the **reverse direction**: can SketchUp *load* project data *from*
[PH-Navigator](https://github.com/bldgtyp/ph-navigator)?

Nothing beyond this question is decided — scope, the data of interest (assemblies? apertures?
climate? whole models?), the transport, and the runtime shape are all open, and get scoped with Ed
before any spike plan is written.
