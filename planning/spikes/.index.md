# spikes — throwaway spike code

Kept regardless of outcome, per `AGENTS.md`. All of it is read-only against the corpus and
against designPH data — **except `library-import/`**, whose whole point is writing
`DesignPH_dict`, under POC #3's scoped amendment to hard rule 2 (staged copies only, model level
only, capture-diff after every write). Which POC each subfolder belongs to:

| Subfolder | POC |
|---|---|
| `phase0/` · `phase1/` · `phase2/` · `pyodide/` | [`01_sketchup-export/feasibility/`](../01_sketchup-export/feasibility/.index.md) — spike Phases 0–3 |
| `poc/` | [`01_sketchup-export/implementation/`](../01_sketchup-export/implementation/.index.md) — capture-analysis scripts |
| `headless/` | [`02_headless-reader/`](../02_headless-reader/.index.md) — the C-SDK gates and collector |
| `library-import/` | [`03_library-import/`](../03_library-import/.index.md) — Spikes L-A + L-B write paths, PHN mapper, verification |

Every Python script is PEP 723 + `uv run` — no venv, no install. Run them from the repo root.
Every Ruby script is read-only, syntax-checked with `ruby -c`, and pasted into SketchUp's Ruby
Console by hand — none of them installs anything.

## `phase2/`

Two Python scripts, no corpus access at all — this pair reads PyPI, the Pyodide lock files, and the
published wheels. Both are network-dependent and safe to re-run.

| Script | Produces |
|---|---|
| `purity_audit.py` | `RESULTS/PHASE-2_dependency-audit.md` + `RESULTS/baselines/phase2_closure.json` — the full universal dependency closure of each root, every package classified **pure** / **Pyodide-built** / **blocker** / **sdist-only**, with wheel sizes. Purity is read from PyPI's file list, *not* from what `pip download` picks for this machine's platform |
| `import_reachability.py` | `RESULTS/PHASE-2_import-reachability.md` — the question the audit cannot answer: is the impure package actually *imported* on our path. Static scan of every wheel (top-level vs guarded), then an empirical probe that installs the pins `--no-deps` and runs HBJSON → `PhxProject` → WUFI XML + METr JSON with none of the impure packages present |

The two disagree for four packages, and `import_reachability.py` is the one that decided Phase 3's
scope. `honeybee-core` *declares* `honeybee-schema` → `pydantic` → `pydantic-core` (Rust) and never
imports it outside `cli/`; PHX *declares* `lxml` and `xlwings` and its write path imports neither.

Regeneration, from the repo root:

```bash
uv run planning/spikes/phase2/purity_audit.py honeybee-ph PHX \
  --md planning/01_sketchup-export/feasibility/RESULTS/PHASE-2_dependency-audit.md \
  --json planning/01_sketchup-export/feasibility/RESULTS/baselines/phase2_closure.json

uv run planning/spikes/phase2/import_reachability.py \
  --md planning/01_sketchup-export/feasibility/RESULTS/PHASE-2_import-reachability.md
```

`purity_audit.py` defaults to checking Pyodide `314.0.5` and `0.29.4`; pass `--pyodide <version>`
(repeatable) when the version Phase 3 actually vendors is decided.

## `pocs/01_sketchup-export/`

Two Python scripts, no SketchUp and no corpus access — they read **only the extraction JSON already
captured in `pocs/01_sketchup-export/_private/fixtures/`**. They exist because that capture turned out to answer more
than the run producing it had asked.

| Script | Produces |
|---|---|
| `solve_window_parent.py` | *(stdout)* Recovers the window parent transform from the **first, defective** Adelphi capture — local +Z onto host normal by Kabsch, local origin onto host plane by least squares — then scores the four candidate rough-opening conventions against the real host polygons. Reproduces `DESIGNPH_DATA_MODEL.md` §9.3's independently measured parent to 4 dp, and settles the corner convention at **46/46 vs 23/46** |
| `patch_and_translate.py` | A **rehearsal** extraction (scratch path, marked in `generated_by`) with the two window fields rebuilt as the fixed collector will emit them, plus the real translator's report on it. This is how contract §8.1/§8.2's fixes were verified against Adelphi's real geometry with no SketchUp session |

⚠ **A rehearsal is not a capture.** `patch_and_translate.py`'s output may not be used as a fixture or
quoted as evidence about a live model; it de-risks POC-2's re-capture, it does not replace it.

⚠ **They read `…extraction.PRE-FIX.json`, not the current fixture.** The defective v1 capture is what
carries the parent-relative transform these scripts solve *from*; against a corrected v2 capture
`solve_window_parent.py` has nothing to recover. That file is kept in `pocs/01_sketchup-export/_private/` for exactly
this reason.

✅ **How accurate the rehearsal turned out to be**, once the real re-capture landed: identical on
every count, identical TFA to three decimals, and 323,780 vs 323,779 bytes of HBJSON. The single
divergence was **0.3 µm** wide — one window that the rehearsal's numpy arithmetic put exactly on its
host's boundary and SketchUp put a third of a micron past it, flipping a tolerance-free honeybee
predicate. Worth knowing both that the method works and where its floor is.

```bash
uv run planning/spikes/poc/solve_window_parent.py
uv run planning/spikes/poc/patch_and_translate.py [OUT.json]
```

## `library-import/`

POC #3's writing spikes — the ONLY writing code in `spikes/` (see the exception at the top).
⭐ **Both ran 2026-08-31, both gates PASS** (`../03_library-import/RESULTS/`);
`write_library.rb` is the reference for the write recipe designPH accepts. L-A's assets — one
Ruby paste-in, three Python tools, all verified before any SketchUp session:

| Script | Does |
|---|---|
| `write_library.rb` | ★ the A-1 paste-in: writes one assembly (+ layer table), one frame, one glazing at model level, native serialiser, matching each key's existing base64 style. Dry-run on paste; `DPHL.write!` commits; `DPHL.revise!` is the O-8 rename+retune. Guarded: `LIBIMPORT`-titled copies only, refuses 3.x |
| `offline_rehearsal.rb` + `rehearse.py` | run the whole write path on the real tables with a stubbed `Sketchup` and verify every byte (untouched rows identical, styles preserved, marker values exact). **5/5 scenarios PASS 2026-08-31.** ⚠ A rehearsal is not a capture |
| `dump_model_tables.py` | the authoritative before/after read: SDK **live-state** dump of every model-level key (incl. `frames_ud`/`glazing_ud`, which contract-v2 captures omit) + `--diff` naming changed rows/columns |
| `prep_copies.py` | stages the LIBIMPORT copies + `_private/MANIFEST.md`; never overwrites |

**Spike L-B (⭐ PASS 2026-08-31, same evening)** adds the PHN-mapping layer on the same machinery —
the contract it implements is [`../03_library-import/CONTRACT_phn-library.md`](../03_library-import/CONTRACT_phn-library.md):

| Script | Does |
|---|---|
| `map_phn.py` | ★ the executable contract: real PHN data (`_private/phn/linde_phn_library.json`) → `_private/payload/lb_payload.json` + the `lb_expectations.md` grading sheet. Films from (type, exterior_condition); per-layer segments packed into PHPP's 3-path model (refusal beyond \|F\|=2); ISO 6946 intended U + Error % via the POC-1-verified function; the packing's absorbed alignment Δ printed per assembly |
| `write_library_b.rb` | data-driven paste-in: writes the WHOLE payload (8 assemblies + layer tables, 9 frames, 2 glazings), L-A's recipe verbatim, same guards. `DPHLB.write!`; `DPHLB.write!(:probe)` adds the foreign `phn_id` column on the dedicated `-xc` copy (the update-key probe) |
| `offline_rehearsal_b.rb` + `rehearse_b.py` | the B rehearsal: byte checks as in L-A **plus** the closing arithmetic loop — U recomputed from the written bytes must equal the intended U. **4/4 scenarios PASS 2026-08-31** (Bluff Reach fill, Linde wrapped-style, Adelphi create-all, probe) |
| `prep_copies_b.py` | stages the three L-B copies; APPENDS to `_private/MANIFEST.md` (the L-A table is evidence) |

⚠ Needs `../headless/_private/` staged (the SDK and corpus copies). `_private/` here is
gitignored client data — copies, baselines, rehearsal state, PHN pulls, Ed-session outputs.
