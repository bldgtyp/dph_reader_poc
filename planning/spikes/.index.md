# spikes — throwaway spike code

Kept regardless of outcome, per `AGENTS.md`. This is the only code that belongs in the repo before
Phase 3's gate. All of it is read-only against the corpus and against designPH data.

Every Python script is PEP 723 + `uv run` — no venv, no install. Run them from the repo root.
Every Ruby script is read-only, syntax-checked with `ruby -c`, and pasted into SketchUp's Ruby
Console by hand — none of them installs anything.

## `phase2/`

Two Python scripts, no corpus access at all — this pair reads PyPI, the Pyodide lock files, and the
published wheels. Both are network-dependent and safe to re-run.

| Script | Produces |
|---|---|
| `purity_audit.py` | `RESULTS/PHASE-2_dependency-audit.md` + `RESULTS/baselines/phase2_closure.json` — the full universal dependency closure of each root, every package classified **pure** / **Pyodide-built** / **blocker** / **sdist-only**, with wheel sizes. Purity is read from PyPI's file list, *not* from what `pip download` picks for this machine's platform |
| `import_reachability.py` | `RESULTS/PHASE-2_import-reachability.md` — the question the audit cannot answer: is the impure package actually *imported* on our path. Static scan of every wheel (top-level vs guarded), then an empirical probe that installs the pins `--no-deps` and runs HBJSON → `PhxProject` → WUFI XML + METr JSON with none of the impure packages present |

The two disagree for four packages, and `import_reachability.py` is the one that decided Phase 3's
scope. `honeybee-core` *declares* `honeybee-schema` → `pydantic` → `pydantic-core` (Rust) and never
imports it outside `cli/`; PHX *declares* `lxml` and `xlwings` and its write path imports neither.

Regeneration, from the repo root:

```bash
uv run planning/spikes/phase2/purity_audit.py honeybee-ph PHX \
  --md planning/RESULTS/PHASE-2_dependency-audit.md \
  --json planning/RESULTS/baselines/phase2_closure.json

uv run planning/spikes/phase2/import_reachability.py \
  --md planning/RESULTS/PHASE-2_import-reachability.md
```

`purity_audit.py` defaults to checking Pyodide `314.0.5` and `0.29.4`; pass `--pyodide <version>`
(repeatable) when the version Phase 3 actually vendors is decided.

## `poc/`

Two Python scripts, no SketchUp and no corpus access — they read **only the extraction JSON already
captured in `poc/_private/fixtures/`**. They exist because that capture turned out to answer more
than the run producing it had asked.

| Script | Produces |
|---|---|
| `solve_window_parent.py` | *(stdout)* Recovers the window parent transform from the **first, defective** Adelphi capture — local +Z onto host normal by Kabsch, local origin onto host plane by least squares — then scores the four candidate rough-opening conventions against the real host polygons. Reproduces `DESIGNPH_DATA_MODEL.md` §9.3's independently measured parent to 4 dp, and settles the corner convention at **46/46 vs 23/46** |
| `patch_and_translate.py` | A **rehearsal** extraction (scratch path, marked in `generated_by`) with the two window fields rebuilt as the fixed collector will emit them, plus the real translator's report on it. This is how contract §8.1/§8.2's fixes were verified against Adelphi's real geometry with no SketchUp session |

⚠ **A rehearsal is not a capture.** `patch_and_translate.py`'s output may not be used as a fixture or
quoted as evidence about a live model; it de-risks POC-2's re-capture, it does not replace it.

⚠ **They read `…extraction.PRE-FIX.json`, not the current fixture.** The defective v1 capture is what
carries the parent-relative transform these scripts solve *from*; against a corrected v2 capture
`solve_window_parent.py` has nothing to recover. That file is kept in `poc/_private/` for exactly
this reason.

✅ **How accurate the rehearsal turned out to be**, once the real re-capture landed: identical on
every count, identical TFA to three decimals, and 323,780 vs 323,779 bytes of HBJSON. The single
divergence was **0.3 µm** wide — one window that the rehearsal's numpy arithmetic put exactly on its
host's boundary and SketchUp put a third of a micron past it, flipping a tolerance-free honeybee
predicate. Worth knowing both that the method works and where its floor is.

```bash
uv run planning/spikes/poc/solve_window_parent.py
uv run planning/spikes/poc/patch_and_translate.py [OUT.json]
```
